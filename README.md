# Связь / 54
Учебный чат-бот технической поддержки колледжа. Студенты регистрируются на главной странице, техник создаётся из терминала. Все кабинеты и обращения в примерах вымышлены.

## Запуск из папки проекта
Python 3.11 или 3.12. Создайте виртуальное окружение и активируйте его.
```sh
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```
Откройте http://127.0.0.1:8000. Для демонстрации откройте второй браузер или приватное окно для техника. На главной странице создайте студента, введите «В кабинете 305 нет интернета», ответьте на уточнение и создайте заявку. В окне техника обновите очередь, добавьте комментарий, возьмите заявку в работу, затем укажите результат и закройте её. В первом окне обновите список.

## Проверка и документация
`python -m unittest -v` запускает тесты на временных базах. Интерактивная схема API доступна по /docs, её JSON — /openapi.json. HELP DESK использует SQLite; путь задаётся переменной HELPDESK_DB (по умолчанию desk.sqlite). Схема v1 создаётся при запуске. Для следующей версии подготовьте миграцию по PRAGMA user_version и проверьте её на копии базы. Для серверного запуска используйте постоянный том для БД и обратный прокси с HTTPS перед Uvicorn. Публичный экземпляр не развёрнут.

## Бот в мессенджере MAX
Студент общается с ботом в личном диалоге MAX. Напишите «В кабинете 305 нет интернета», ответьте на уточнение и получите номер заявки. Для просмотра ответа техника отправьте /status, для отмены черновика — /cancel. Техник открывает веб-панель по основному адресу сервера. Учётная запись студента привязана к идентификатору MAX.

### Подключение к MAX
1. Создайте бота на платформе MAX для бизнеса и получите токен. Храните MAX_BOT_TOKEN в секретах хостинга. Задайте MAX_WEBHOOK_SECRET случайной строкой, например результатом команды python -c "import secrets; print(secrets.token_hex(32))".
2. Разместите приложение на сервере с постоянным диском для SQLite и публичным HTTPS. Запустите python -m uvicorn max_bot:app за HTTPS-прокси. Создайте техника командой python app.py с тем же HELPDESK_DB.
3. В окружении сервера один раз выполните python max_bot.py https://ВАШ-ДОМЕН/max/webhook (подставьте действительный домен). Сервер должен доверять цепочке сертификатов MAX.
4. Откройте зарегистрированного бота в MAX и нажмите «Начать». Проверьте создание заявки, её обработку в панели и команду /status. Доступность GitHub-репозитория сама по себе обработчик не запускает.

Документация: https://dev.max.ru/docs-api/methods/POST/subscriptions и https://dev.max.ru/docs-api/methods/POST/messages .
